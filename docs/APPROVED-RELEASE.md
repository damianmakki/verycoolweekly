That badge alone is not proof of a remotely scheduled Note. Verify the existing draft identity and initial list status, exact copy and chosen time, then use the final Schedule action under the standing authorization and verify the resulting scheduled list entry. Never infer a duplicate solely from this intermediate badge. If an action’s result is uncertain, inspect the list before retrying.
